# megarohas_multichat

[English](README.md) | **Русский**

Локальный агрегатор чатов **Twitch + YouTube** в один красивый оверлей для OBS.
Без API-ключей, без OAuth, без сторонних сервисов, **ноль зависимостей** — один
процесс Node.js, который крутится на твоей машине.

- Вставляешь ссылки на стримы — сообщения с обеих платформ появляются в одном
  чате в порядке прихода, в реальном времени.
- Оверлей — обычная страница на `localhost`, которую OBS показывает через
  Browser Source (фон прозрачный).
- Эмоуты Twitch (включая BTTV / FFZ / 7TV), кастомные эмодзи YouTube,
  Super Chat / Super Sticker, спонсорства, сабы и рейды, значки ролей.
- Модерация уважается: удалённые модераторами сообщения и баны убирают
  сообщения и с оверлея.
- Сообщения появляются строго по одному с плавной анимацией (60 fps),
  верхнее никогда не обрезается — если не влезает целиком, красиво уплывает.

## Запуск

Самый простой путь — **готовый бинарник** со страницы
[Releases](https://github.com/megarohas/megarohas_multichat/releases):
один исполняемый файл, ничего устанавливать не нужно. `config.json`,
папка `fonts` и `error.log` появятся рядом с ним.

- Windows: `megarohas_multichat-win-x64.exe` — просто запусти.
- Linux: `chmod +x megarohas_multichat-linux-x64 && ./megarohas_multichat-linux-x64`
- macOS: снять карантин и запустить (бинарник подписан ad-hoc, поэтому при
  первом запуске — правый клик → «Открыть», либо `xattr -d com.apple.quarantine <файл>`).
  Сборки для macOS/Linux кросс-собраны и обкатаны меньше винды — если что, issue.

Запуск из исходников — нужен Node.js 18+, есть два пути:

1. **Портативный** (ничего не ставится в систему): скачай zip с
   [nodejs.org](https://nodejs.org/en/download) («Standalone / Binary», Windows x64),
   распакуй так, чтобы получилось `runtime\node\node.exe` рядом с `server.js`.
2. **Системный**: просто установи Node.js.

Дальше — Windows:

```bat
start.cmd
```

Linux / macOS:

```bash
./start.sh
```

(оба скрипта сами берут портативный Node из `runtime/node`, если он лежит
рядом — на Windows `runtime\node\node.exe`, на Linux/macOS
`runtime/node/bin/node`, — иначе системный `node`).

- Панель управления: **http://127.0.0.1:3131/**
- Оверлей для OBS: **http://127.0.0.1:3131/overlay**

Хочешь панель отдельным окном приложения, а не вкладкой — запускай
`start-window.cmd` / `./start-window.sh` (используется режим `--app`
установленного Edge/Chrome/Chromium).

### Сеть и порт

- Сервер по умолчанию доступен **всем устройствам локальной сети** — адреса
  вида `http://192.168.x.x:3131/…` печатаются в консоли и показываются в
  панели (удобно для OBS на другом ПК или проверки с телефона). Windows при
  первом запуске спросит разрешение брандмауэра — разреши для частных сетей.
  Нужно только на этом ПК — поставь `"host": "127.0.0.1"` в `config.json`.
- Если порт занят, сервер сам возьмёт следующий свободный и напечатает
  фактический адрес.

## Использование

1. Открой панель, вставь ссылки:
   - Twitch: `twitch.tv/канал` (годятся и popout-чат, и мобильные ссылки)
   - YouTube: `youtube.com/watch?v=…`, `youtube.com/live/…`, `youtu.be/…`
     или просто `youtube.com/@канал/live` — тогда ссылку можно добавить
     **до начала эфира**: тулза раз в минуту проверяет канал и сама
     подцепится, когда стрим начнётся.
2. В OBS добавь источник «Браузер» с адресом оверлея (размер ~450×700).
3. Кнопка «Тест-сообщения» в панели — чтобы настраивать внешний вид,
   не будучи в эфире.

Ссылки сохраняются в `config.json` и восстанавливаются при перезапуске.

## Параметры оверлея

Добавляются к адресу, соединяются через `&`, например
`http://127.0.0.1:3131/overlay?size=20&dir=top&fade=30`:

| Параметр | Что делает |
|---|---|
| `size=22` | размер шрифта, px |
| `font=Имя` | шрифт: системный по имени, либо файл из папки `fonts` |
| `dir=top` | чат растёт сверху вниз (по умолчанию — снизу вверх) |
| `platform=0` | скрыть значки платформ (Twitch/YouTube) у сообщений |
| `badges=0` | скрыть значки ролей (модератор, VIP, саб, спонсор и т.д.) |
| `fade=20` | прятать сообщение через N секунд |
| `ts=1` | показывать время |
| `origcolors=1` | родные цвета ников Twitch вместо пастельной палитры |
| `limit=40` | потолок сообщений в DOM (страховка, по умолчанию 60) |

**Свои шрифты**: кинь `.ttf` / `.otf` / `.woff` / `.woff2` в папку `fonts`,
имя семейства = имя файла без расширения: `fonts\Rubik.ttf` → `?font=Rubik`.

**Внешний вид** целиком правится в `public/overlay.css` — вверху файла
переменные (фон плашек, скругление, отступы, длительность анимаций и т.д.).

## Как это работает

- **Twitch** — анонимное чтение чата через официальный IRC-гейт
  (`irc.chat.twitch.tv`, логин `justinfan…`). Это штатный способ чтения,
  токены не нужны. Эмоуты BTTV/FFZ/7TV подтягиваются с их публичных API.
- **YouTube** — тот же внутренний API (InnerTube `get_live_chat`), которым
  пользуется веб-страница чата; так работают chat-downloader, yt-dlp и т.п.
  Способ неофициальный: если YouTube поменяет внутренности, надо будет
  обновить `lib/youtube.js` (там прокомментирована актуальная схема).
- Сервер раздаёт панель и оверлей и пушит сообщения по SSE. Всё локально;
  наружу уходят только запросы к самим Twitch/YouTube.

## Сборка бинарников

```bash
node build/build.js all
```

`server.js` склеивается esbuild-ом в один файл, из него и `public/*`
генерируется блоб Node SEA (Single Executable Application) и инжектится в
официальные бинарники Node — Windows, Linux и macOS собираются с одной
машины (macOS подписывается ad-hoc через rcodesign, в виндовый exe
прошивается иконка). Результат — в `dist/`. Нужен интернет; инструменты
сборки ставятся в `build/node_modules` и на готовое приложение не влияют.

Иконка приложения — `assets/icon.ico` (+`public/favicon.svg` для страниц):
хочешь свою — просто замени файлы; `build/make-icon.js` перегенерирует
дефолтную.

## Ограничения

- Читаются только публичные чаты. Members-only чат YouTube требует
  авторизации и не поддерживается.
- Задержка YouTube — пара секунд (поллинг), Twitch — почти нулевая.
- `config.json`: `host`/`port` можно поменять (например, `0.0.0.0`, если OBS
  на другой машине).
