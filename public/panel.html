Оверлей для OBS

В OBS добавь источник «Браузер» (Browser Source) с этим адресом — фон прозрачный, рекомендуемый размер 450×700. Для OBS или браузера на другом устройстве используй адрес «по сети».

Параметры оверлея

?size=22размер шрифта, px
?font=Имяшрифт: системный по имени или файл из папки fonts (имя файла без расширения)
?dir=topчат растёт сверху вниз (по умолчанию — снизу вверх)
?platform=0скрыть значки платформ (Twitch/YouTube)
?badges=0скрыть значки ролей (модер, VIP, саб, спонсор)
?fade=20прятать сообщение через N секунд
?ts=1показывать время сообщения
?origcolors=1родные цвета ников Twitch вместо пастельной палитры
?limit=40потолок сообщений в DOM (по умолчанию 60)
Параметры дописываются к адресу оверлея и соединяются через &: /overlay?size=20&dir=top&fade=30

Справка

  • Свои шрифты — кинь .ttf/.otf/.woff2 в папку fonts рядом с программой и укажи ?font=ИмяФайла.
  • Внешний вид чата — полностью правится в public/overlay.css (при запуске из исходников); переменные — в начале файла.
  • Оконный режим — запусти start-window.cmd (или с флагом --window): эта же панель откроется отдельным окном приложения.
  • Настройки — config.json рядом с программой: port, host (127.0.0.1 — только этот ПК), список ссылок. Ссылку на YouTube-канал вида @канал/live можно добавить до эфира — стрим подхватится сам.
  • Что-то не так? — загляни в error.log рядом с программой; issues — github.com/megarohas/megarohas_multichat.
